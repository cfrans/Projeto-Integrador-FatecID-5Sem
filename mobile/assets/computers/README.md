# Ícones dos computadores

Ícones de [Lucide](https://github.com/lucide-icons/lucide), sob a licença ISC preservada em [LICENSE](LICENSE): [monitor](https://github.com/lucide-icons/lucide/blob/main/icons/monitor.svg), [laptop](https://github.com/lucide-icons/lucide/blob/main/icons/laptop.svg), [gamepad-2](https://github.com/lucide-icons/lucide/blob/main/icons/gamepad-2.svg) e [server](https://github.com/lucide-icons/lucide/blob/main/icons/server.svg).

SVGs originais foram preservados e rasterizados em PNG 96×96. O app aplica tint da paleta ativa; não há biblioteca gráfica adicional. O padrão é Computador; as opções Notebook, PC gamer e Servidor são preferências visuais, sem inferir o hardware real.
