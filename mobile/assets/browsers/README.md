# Logos dos navegadores

Arquivos locais usados somente para identificar os navegadores na lista de restrições, preservando cores e proporções. As marcas pertencem aos respectivos projetos.

| Arquivo | Fonte oficial |
| --- | --- |
| `firefox.png` | [Firefox — browser/branding/official/default128.png](https://github.com/mozilla-firefox/firefox/blob/main/browser/branding/official/default128.png) |
| `chromium.png` | [Chromium — chrome/app/theme/chromium/product_logo_128.png](https://github.com/chromium/chromium/blob/main/chrome/app/theme/chromium/product_logo_128.png) |
| `brave.png` | [Brave — app/theme/brave/product_logo_128.png](https://github.com/brave/brave-core/blob/master/app/theme/brave/product_logo_128.png) |
| `gnome-web.svg`, `gnome-web.png` | [GNOME Web — org.gnome.Epiphany.svg](https://github.com/GNOME/epiphany/blob/main/data/icons/hicolor/scalable/apps/org.gnome.Epiphany.svg) |

Os três primeiros PNGs foram copiados sem alterações. O SVG do GNOME Web foi preservado e rasterizado em PNG 128×128 para uso pelo `Image` nativo, sem biblioteca adicional no app.
